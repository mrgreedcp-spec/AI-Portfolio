# 加拿大电信套餐指南 · HTML 生成 Prompt（新移民 / PR 持有者）

> 用法：把下面「Prompt 正文」整段复制给任意大模型（Claude / ChatGPT 等），即可生成一个单文件、可直接在浏览器打开的 HTML 页面。
> 「参考数据」一节是 2026 年 9 月整理的市场参考价，**套餐价格与优惠变动频繁，发布前务必到运营商官网核实**。

---

## Prompt 正文

```text
# 角色
你是一名资深前端工程师 + 加拿大新移民安家顾问。你熟悉加拿大三大运营商（Rogers / Bell / Telus）、
其子品牌（Fido、Virgin Plus、Koodo、Chatr、Lucky Mobile、Public Mobile）、独立运营商
（Freedom Mobile、Fizz、Videotron 等）以及 CRTC 相关消费者保护规定。

# 任务
生成一个【单文件 HTML】页面（HTML + 内联 CSS + 原生 JavaScript，不依赖任何外部框架、字体或图片），
标题为「加拿大手机套餐选择指南：新移民 vs PR 持有者」。
页面面向中文用户，全部正文使用简体中文，运营商名称、套餐名、证件名称保留英文原文并附中文解释。

# 目标受众（页面必须明确区分以下两类人，并给出不同建议）
A. 新移民 / 新落地（Newcomer）
   - 包括：刚登陆的 PR（持 COPR、PR 卡尚未寄到）、工签持有者、学签持有者
   - 特点：无加拿大信用记录、可能还没有 SIN 或银行账户、地址可能是临时地址、需要尽快有本地号码
     （用于银行开户、SIN 办理、租房、找工作）
B. 已持有 PR 卡的永久居民（PR Holder）
   - 包括：登陆超过 1–3 年、已有 PR 卡、已建立信用记录、有稳定地址与银行账户的人
   - 特点：通常已不在运营商「新移民优惠」时间窗口内；可走正常信用审核；更关注长期性价比、
     家庭共享、合约购机、宽带捆绑、跨境漫游
   - 特别情况：登陆不满 24–36 个月的 PR 仍可能符合 newcomer 优惠，页面需提示「先查自己是否仍在窗口期」

# 页面结构（按顺序实现）
1. 顶部 Hero
   - 标题、一句话副标题、「数据更新日期」徽章（使用下方参考数据的日期）
   - 醒目免责声明：价格仅供参考，以运营商官网为准
2. 身份选择器（核心交互）
   - 两个大按钮 / 分段控件：「我是新移民（刚落地 / 工签 / 学签）」「我是 PR 持有者（已有 PR 卡 + 信用记录）」
   - 切换后，下方的推荐套餐、材料清单、办理流程、注意事项全部随身份动态变化
   - 记住用户上次选择（localStorage，读写包裹在 try/catch 中，失败时默认显示「新移民」）
3. 快速决策流程（3 个问题的小问卷，结果给出推荐类别）
   - Q1 你有加拿大信用记录吗？（有 / 没有 / 不确定）
   - Q2 你每月预算？（< $30 / $30–50 / $50–80 / > $80）
   - Q3 你最看重什么？（最便宜 / 信号覆盖（含郊区、北部）/ 需要美国或国际漫游 / 需要合约分期买手机 / 家庭多号共享）
   - 输出：推荐「预付费子品牌」「Newcomer 后付费优惠」「标准后付费 + 合约购机」「独立运营商」之一，并高亮对应卡片
4. 运营商分层说明
   - 一级品牌（Rogers / Bell / Telus）：覆盖最好、价格最高、合约购机、新移民项目
   - 二级品牌（Fido / Virgin Plus / Koodo）：同网络、价格中等、也有 newcomer 项目
   - 预付费品牌（Chatr / Lucky Mobile / Public Mobile / Fizz）：免信用审核、便宜、无合约、客服多为线上
   - 独立运营商（Freedom Mobile / Videotron 等）：价格激进、城市覆盖好、郊区与室内信号需实测
   - 用简单的层级图或卡片网格展示，每层写清「适合谁 / 不适合谁」
5. 套餐对比表（数据驱动）
   - 所有套餐数据写在一个 JS 数组 PLANS 中（字段见下方「数据结构」），表格由 JS 渲染
   - 支持：按身份过滤、按月费排序、按数据量排序、筛选「免信用审核」「含美国漫游」「5G」
   - 每行显示：运营商、品牌层级、套餐名、月费（CAD，税前）、流量、网络（4G/5G）、漫游、
     是否需信用审核、适用身份标签（新移民 / PR / 两者）、备注
   - 手机端（< 640px）表格改为卡片列表，禁止整页横向滚动
5b. 预付费与实体 SIM 卡（新增区块，放在对比表之后）
   - 表 1：预付费 / Newcomer 后付费 / 标准后付费 三列对比：信用审核、证件、付款方式、合约、参考月费、
     网络速度、流量用完后果、购机、漫游、家庭多线、客服、忘记付款的后果、最适合人群
   - 表 2：实体 SIM 卡 vs eSIM：形式、卡费、购买渠道、能否落地前准备、手机要求（提示国行 iPhone 大多不支持 eSIM，
     可在「设置 → 通用 → 关于本机」查看 EID）、保留国内号码、换手机、丢失风险、更适合谁
   - 表 3：各预付费品牌 SIM 卡速查：品牌、网络、实体卡价格、eSIM 价格、速度、主力套餐、购买地点、停机与号码回收规则
   - 提示已停止新开户的预付费：Telus Prepaid（2026-07-01 起转 Koodo Prepaid）、Bell Prepaid（转 Lucky Mobile）、
     Rogers Prepaid（转 Chatr）
   - 实体卡购买激活步骤（有序列表）：确认解锁 → 选购买地点 → 带护照 → 输入 ICCID 激活并选区号 → 开自动充值 → 记下账户号和 PIN
   - 小贴士：机场买卡更贵、皮尔逊机场可买的卡、用充值卡续费、SIM 卡费不属于 CRTC 禁止的激活费
6. 办理材料清单（按身份切换，可勾选）
   - 新移民清单：
     · 有效护照（必备）
     · 身份证明其一：COPR（确认永久居民身份信）/ 工签 Work Permit / 学签 Study Permit
     · 第二张带照片的证件（若有）：省驾照 / 省 ID / 国际驾照（部分门店要求两种 ID）
     · 加拿大地址（临时住址、Airbnb、朋友地址均可，部分运营商需要账单寄送地址）
     · 支付方式：信用卡（首选，可含国内 Visa/Mastercard）或借记卡 / 预付费充值卡
     · 可选：SIN（社会保险号，不是必需，也不应随意提供）、加拿大银行账户、雇佣信 / 录取信
     · 可选：押金（无信用记录又不符合 newcomer 项目时，后付费通常需 $150–$300 可退押金）
     · 手机：确认是否已解锁（unlocked）、是否支持加拿大频段、是否支持 eSIM
   - PR 持有者清单：
     · PR 卡（Permanent Resident Card）
     · 省驾照或省 ID
     · 加拿大信用卡（用于信用审核与自动扣款）
     · 住址证明（水电账单 / 银行对账单，部分门店需要）
     · 可选：SIN（仅在运营商明确要求信用审核时提供，可用其他方式替代）
     · 若携号转网：原运营商账号、账户 PIN / 转网授权码、IMEI
   - 清单每项可勾选，进度条显示完成百分比；勾选状态存 localStorage（同样 try/catch）
   - 每项旁加「为什么需要」的折叠说明
7. 办理流程时间线（按身份切换）
   - 新移民：落地前（购买可在机场激活的 eSIM / 预付费 SIM）→ 落地当天（机场或商场门店激活，
     获取本地号码）→ 第 1 周（用该号码办银行卡、SIN）→ 第 1–3 个月（评估是否转 newcomer 后付费方案）
     → 第 6–12 个月（申请信用卡、建立信用，押金到期退还）
   - PR 持有者：比价 → 检查是否仍在 newcomer 窗口 → 携号转网 / 合约购机 → 设置自动扣款 →
     每年黑五 / 节礼日重新比价
8. 省钱技巧与避坑（按身份给出不同重点）
   - 黑五、节礼日、返校季（8–9 月）通常是全年最低价
   - 线上专享价、BYOD（自带手机）比合约便宜
   - 预付费品牌常有自动充值折扣、推荐码奖励
   - 合约购机（如 24 个月分期）提前解约需结清机器余款
   - 2026 年 6 月 12 日起，CRTC 新规禁止收取套餐激活费、改套餐费、解约费（机器余款不在此列）——
     页面需提示「以最新 CRTC 公告为准」
   - 防诈骗：运营商不会电话索要 SIN 或验证码；警惕「移民局 / CRA」冒充电话
   - 郊区 / 北部地区优先考虑三大网络；独立运营商请先查覆盖地图
9. FAQ（手风琴折叠）
   - 没有 SIN 能办手机卡吗？
   - PR 卡还没寄到，只有 COPR 可以办 newcomer 优惠吗？
   - 学签 / 工签到期后手机合约怎么办？
   - 可以继续用国内手机吗？需要解锁吗？
   - eSIM 和实体 SIM 怎么选？
   - 押金多久退？
   - 家庭计划（多号码）如何更省？
   - 如何携号转网（Port-in）？
10. 页脚
    - 数据来源列表（运营商官网链接、CRTC 官网）
    - 「最后更新：YYYY-MM-DD」
    - 免责声明

# 数据结构（PLANS 数组每个对象）

  tier: "independent",                 // "big3" | "flanker" | "prepaid" | "independent"

# 设计要求
- 风格：清爽、可信、信息密度适中；主色使用枫叶红 #D52B1E 的柔和版本做强调，不要大面积纯红
- 使用 CSS 变量定义颜色，支持浅色 / 深色模式（prefers-color-scheme），body 明确设置背景色
- 响应式：手机优先，左右留 16px 边距，任何宽度下不出现整页横向滚动
- 字体：系统字体栈（-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif）
- 可访问性：语义化标签（header/nav/main/section/table/footer）、按钮可键盘操作、
  颜色对比度满足 WCAG AA、表格有 <caption> 和 <th scope>
- 标签颜色：「免信用审核」绿色、「Newcomer 专享」蓝色、「需押金」橙色、「PR 适用」紫色
- 顶部固定小导航：身份切换 / 对比表 / 材料清单 / 流程 / FAQ 锚点跳转

# 内容准确性要求
- 所有价格标注「CAD / 月，税前」，并在页面顶部显示数据日期
- 不确定的数据一律写「待核实」，不要编造具体套餐名或价格
- 各运营商 newcomer 项目的时间窗口（常见为登陆后 12–36 个月）以官网为准，页面给出「去官网确认」链接
- 不要建议用户提供不必要的个人信息（尤其是 SIN）

# 输出格式
- 只输出一个完整的 HTML 文件代码块（<!doctype html> 开头），不要额外解释
- 代码中用注释分隔各区块，方便后续更新 PLANS 数据
```

**通用要点**

- **新移民项目**：Rogers、Bell、Telus、Fido、Virgin Plus、Koodo、Freedom 均有 newcomer 项目，对登陆后一定期限内（常见 24–36 个月）的 PR、工签、学签持有者免除加拿大信用审核；具体条件各家不同且会调整。
- **押金方案**：不符合 newcomer 项目时，三大运营商通常接受 $150–$300 可退押金开通后付费，约一年按时缴费后退还。
- **常见材料**：护照 + COPR / PR 卡 / 工签 / 学签其一 + 带照片证件 + 加拿大地址（临时地址也可）+ 支付方式。
- **CRTC 新规**：2026 年 6 月 12 日起，运营商不得收取套餐激活费、改套餐 / 升级费、解约费。
