# 雅思写作精讲 · 第四课材料

针对舒同学第三课反馈设计：**想法不缺，缺的是把想法装进英文句子的通道**。
所以本课不练"想论点"，只练"装"——词组 → 句子 → 段落，全部由中译英驱动。

## 交付物

| 文件 | 页数 | 说明 |
| --- | --- | --- |
| `第四课课堂练习_雅思写作.docx` | 19 | 七个模块，含参考答案与写作提示 |
| `第四课课后巩固_雅思写作.docx` | 9 | 五块作业 + 自评清单 + 错题本 |

## 课堂七模块（约 130 分钟）

| 模块 | 内容 | 量 |
| --- | --- | --- |
| 1 | 词汇搭配库（教育 / 科技 / 通用论证） | 60 组，每组带中式陷阱 |
| 2 | 中译英 L1 · 词组级 | 30 题 |
| 3 | 中译英 L2 · 句子级（四组高分句式） | 24 题 |
| 4 | 高分例句库（按功能分六类） | 40 句 |
| 5 | 范文精读 ×2 + 骨架拆解 | 2 篇 |
| 6 | 段落组装（给零散关键词 → 写成逻辑段） | 3 段 |
| 7 | 中译英 L3 · 段落级 | 3 段 |

## 课后五块

A 搭配默写 40 · B 句子中译英 20 · C 段落中译英 2 · D 范文仿写 1 篇 · E 限时独立写作 1 篇

## 针对性说明

| 舒同学的问题 | 本课对应设计 |
| --- | --- |
| 想法零散，串不成篇 | 模块 6 段落组装：直接给她课上会蹦的那类关键词，要求组装成 4–5 句的段 |
| 中文思维，句意衔接不地道 | 三级中译英全程锁定"先定意思，再逼结构" |
| 词汇 / 固定搭配储备不足 | 60 组搭配 + 40 句高分例句，每条标中式陷阱 |
| 长难句式储备不足 | L2 四组句式：名词化主语 / 让步转折 / 非谓语 / 形式主语与比较 |
| 不会拆解模仿范文 | 范文给骨架表（段落功能 + 首句 + 展开方式 + 过渡词），作业 D 直接照搬骨架 |

**名词化主语**是本课的核心抓手：她最典型的中式句是 `Because many students only care about
the exam result, so they...`，把原因压成名词短语当主语（`An excessive focus on examination
results leaves students...`）是从 6 分到 7 分最快的一步。
