## 逐题两页坐标

见 `deck.py` 的 `LAYOUT` 字典，三套版式：

- `qa` —— 普通题：题干(1.02 高) → 入口/证据(2.72) → 替换/答案(4.86)
- `qa_mcq` —— 选择题：题干(0.58) → 选项(2.06) → 入口/证据(3.56) → 替换/答案(5.38)
- `sent` —— 长难句：原句(1.42) → 主干/拆解/中文(2.92) → 词汇(5.55)

三栏卡片页：x = 0.72 / 4.74 / 8.76，宽 3.75，标签 y=1.62，面板 y=2.00 高 3.95。

## 字号自适应

`fit_size(paras, w, h, sizes)` 从大到小挑第一个放得下的。各处的候选序列：

| 位置 | 候选字号 |
| --- | --- |
| 标题 | 30, 27, 24, 22, 20 |
| 题干（普通） | 24, 22, 20, 18, 17, 16 |
| 题干（选择题） | 23, 21, 19, 18, 17 |
| 选项 | 18, 17, 16, 15, 14 |
| 一般面板 | 19 … 11 |
| 答案面板 | 21, 20, 19, 18, 17, 16 |
| 三栏卡片 | 22, 20, 18, 17, 16, 15, 14 |
| 长条方法页 | 23, 21, 20, 19, 18, 17, 16, 15 |

字宽模型：汉字与全角标点 1.0 em；大写 0.68；数字 0.55；`iljItf.,;:'"!|()[]{}` 与空格 0.30；`mwMWQ@%&` 0.85；其余小写 0.52。行高按字号 × 1.26。
